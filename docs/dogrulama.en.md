# Verification

**Only projects that pass the standard UA test set reach the final.** Verification has three layers.

## Three layers

1. **Your own test:** You fill in the criteria list and upload evidence for each item.
2. **Technical committee test:** The committee runs the same scenarios for every project and scores them. The proposed starting threshold is 80% of the checklist plus all required items.
3. **ICANN observation:** An observer from the ICANN UA team is requested.

A project that fails gets one chance to fix and resubmit.

## UA-Ready badge

Projects that pass verification receive a **UA-Ready** badge they can use on their website and application page.

!!! warning "To be confirmed"
    We will confirm whether ICANN gives formal per-project approval. If not, the badge is issued in the organizers' name and ICANN only observes the process.

## Preparation tips

- Fix forms and validation rules first; most bugs are there.
- Check database column types and encoding (UTF-8).
- Test end to end with test addresses; sending and receiving real email exposes problems.
- Use the mentor hours.
