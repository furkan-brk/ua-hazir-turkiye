# Municipality e-application form

<div class="concept-meta"><span class="badge cat">Public Sector and Education</span> <span class="badge lv-o">Intermediate</span></div>

<div class="concept-lead" markdown>
Make a municipal or agency portal where citizens apply work smoothly with email addresses and domains that use Turkish characters.
</div>

**Who is it for?** Municipalities, public agencies and the companies that supply their software.

=== "UA touchpoints"

    - Applicant email and institutional domain fields
    - Application tracking number emails
    - Petition PDF output
    - Admin reports and exports

=== "Turkish test scenarios"

    - [ ] Define an institutional address such as `müdürlük@büyükşehir.bel.tr`
    - [ ] Apply with `çağlar@örnek.com` and receive the tracking email
    - [ ] Check the address is readable in the PDF petition

=== "Success criteria"

    - [ ] Application and tracking flows work with an EAI address
    - [ ] Addresses stay intact in PDF and report output

**Suggested technology:** Java Spring or .NET, Oracle/PostgreSQL
