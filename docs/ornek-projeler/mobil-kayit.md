# Mobil kayıt ve e-posta doğrulama akışı

**Kategori:** Mobil · **Zorluk:** Orta

!!! tip "Özet"
    Flutter veya React Native uygulamasının kayıt, giriş ve e-posta doğrulama akışını Türkçe karakterli adreslerle çalışır hale getirmek.

## Kimin işine yarar?

Mobil uygulama geliştiren girişimler ve ajanslar.

## UA dokunma noktaları

- Kayıt ekranındaki e-posta klavyesi ve doğrulaması
- Doğrulama bağlantısı ve derin bağlantı (deep link)
- Hesap kurtarma e-postası
- Profil ekranında adres gösterimi

## Türkçe test senaryoları

- [ ] `şükrü@örnek.com` ile kayıt ol
- [ ] Doğrulama bağlantısını telefonda aç
- [ ] Profilde adresin tam göründüğünü doğrula

## Önerilen teknoloji

Flutter veya React Native, Firebase/özel API

## Başarı ölçütü

- [ ] Kayıt, doğrulama ve kurtarma akışları EAI adresiyle çalışır
- [ ] Uygulama ve sunucu doğrulaması aynı kuralları kullanır
