# Mobile sign-up and email verification flow

**Category:** Mobile · **Difficulty:** Intermediate

!!! tip "Summary"
    Make the sign-up, login and email verification flow of a Flutter or React Native app work with Turkish-character addresses.

## Who is it for?

Startups and agencies building mobile apps.

## UA touchpoints

- Email keyboard and validation on the sign-up screen
- Verification link and deep link
- Account recovery email
- Address display on the profile screen

## Turkish test scenarios

- [ ] Register with `şükrü@örnek.com`
- [ ] Open the verification link on the phone
- [ ] Check the address shows fully on the profile

## Suggested technology

Flutter or React Native, Firebase/custom API

## Success criteria

- [ ] Sign-up, verification and recovery flows work with an EAI address
- [ ] App and server validation use the same rules
