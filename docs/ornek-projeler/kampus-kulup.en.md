# Campus clubs and events platform

**Category:** Public Sector and Education · **Difficulty:** Beginner

!!! tip "Summary"
    Make a platform where student clubs manage membership and event announcements UA-ready.

## Who is it for?

Universities, student communities and teams building campus apps.

## UA touchpoints

- Sign-up and login with a student email
- Event announcement and invitation emails
- Bulk email import (CSV)
- Member search and sorting

## Turkish test scenarios

- [ ] Join with `şeyma@öğrenci.edu.tr`
- [ ] Import 50 members with Turkish characters from CSV
- [ ] Sort the member list alphabetically

## Suggested technology

Django or Node.js, PostgreSQL

## Success criteria

- [ ] Membership and announcement flows work with an EAI address
- [ ] Import and sorting handle Turkish characters correctly
