# Make your project recognize every address in the world.

**UA-Ready Türkiye 2027** is a compliance competition that makes existing projects Universal Acceptance (UA) ready, so addresses like `şükrü@çiçek.com.tr` work everywhere.

[How it works](program.md){ .md-button .md-button--primary }
[Example projects](ornek-projeler/index.md){ .md-button }

</div>

## This is not a hackathon

We don't build products from scratch. You bring **a project that already works**, make it UA-ready in about 4 weeks, and if it passes verification you present it to an expert jury in the final.

<div class="grid cards" markdown>

- :material-file-send:{ .lg .middle } **1. Call**

    Apply with a working web, mobile, desktop, email, library or API project.

- :material-wrench:{ .lg .middle } **2. Adaptation**

    Fix your project with ICANN training, mentor hours and a test email system that supports Turkish characters.

- :material-check-decagram:{ .lg .middle } **3. Verification**

    A technical committee runs the standard UA test set. Pass it and you earn the **UA-Ready** badge.

- :material-trophy:{ .lg .middle } **4. Final**

    Finalists give a live demo to the expert jury; the top three receive prizes.

</div>

## Why it matters

!!! example "What happens today"
    Many sign-up forms reject `şükrü@örnek.com` as an "invalid email". `İSPARTA` and `ısparta` are treated as different users. Notification emails never arrive. This keeps millions of people from using the internet in their own language.

Universal Acceptance means every valid domain name and email address works in every application, regardless of language, script or length. See [Universal Acceptance](universal-acceptance.md) for details.
