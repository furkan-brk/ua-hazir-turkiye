# Participation

**Any software product that accepts, processes or displays domain names or email addresses can apply.** The only requirement is a working version of the project on the application date.

## Which projects?

- Websites and web applications (sign-up, login, membership forms)
- Mobile apps (iOS, Android)
- Desktop software and email clients
- CMS plugins, open-source libraries and frameworks
- APIs and backend services (email validation, CRM, notifications)

## Who can apply?

Student teams, startups, SMEs, software units of public institutions and the open-source community. A team has at most 4 people and submits one project.

## Eligibility

- [ ] The project has a working version
- [ ] At least one team member can change the project's code
- [ ] The project can run in a testable environment
- [ ] The application briefly describes the UA scope (which inputs and outputs are affected)
