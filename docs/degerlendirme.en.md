# Judging

**An expert jury of up to five people decides the ranking; more than half of the score is UA compliance depth and technical quality.**

## Jury

An ICANN or UA community representative, someone from the domain name industry (registrar or registry), an academic, a software engineer and an open-source or user experience expert.

## Scorecard

| Criterion | Weight | What is looked for |
| --- | --- | --- |
| UA compliance depth | 35% | Checklist coverage, hard scenarios, EAI flows |
| Technical quality | 20% | Code and architecture, testability, error handling |
| Impact and user base | 20% | How many users and which domain it touches |
| Sustainability and sharing | 15% | Open-source contribution, documentation, reusable solution |
| Presentation and demo | 10% | Live test success, delivery |

In a tie, the higher "UA compliance depth" score wins. Weights are an initial proposal.

## Awards

- **Top three projects:** Prize amounts will be announced once confirmed.
- **Special awards:** Best open-source contribution, hardest UA problem solved, best student team.
- **UA-Ready badge:** All projects that pass verification.
- **Visibility:** Case studies are published and may appear in ICANN's UA Day report.
