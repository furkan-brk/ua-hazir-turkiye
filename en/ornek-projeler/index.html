    Example Projects¶

    Looking for ideas? These are examples; you can apply with your own project too.

    Category

    Web and E-commerce¶

    E-commerce store

    Sign-up, order and invoice emails work with Turkish-character addresses.

    What is tested? Register and place an order with şükrü@örnek.com

    Appointment system

    Reminder and cancellation emails work with Turkish-character addresses.

    What is tested? Book with gülşen@sağlık.com

    Public Sector and Education¶

    Municipality application form

    A citizen application portal works with Turkish-character addresses.

    What is tested? Define an institutional address such as müdürlük@büyükşehir.bel.tr

    Campus club platform

    Club membership and announcements work with Turkish-character addresses.

    What is tested? Join with şeyma@öğrenci.edu.tr

    School-parent notifications

    Announcements and grade notices work with Turkish-character addresses.

    What is tested? Register şükrü@veli.com for a parent

    Mobile¶

    Mobile sign-up and verification

    Sign-up and verification work in a Flutter or React Native app.

    What is tested? Register with şükrü@örnek.com

    Mobile email app

    Send email to Turkish-character addresses and store them in contacts.

    What is tested? Send an email to şükrü@örnek.com

    Email Infrastructure¶

    Webmail plugin

    Add Turkish-character address support to an open-source webmail such as Roundcube.

    What is tested? Reply to şükrü@örnek.com

    Newsletter service

    Subscriber management and bulk sending work with Turkish-character addresses.

    What is tested? Subscribe and confirm with şükrü@örnek.com

    Support ticket system

    Incoming and outgoing email of a ticket system works.

    What is tested? Send a support email from şükrü@örnek.com

    Developer Tools¶

    Validation library

    A small open-source library that validates Turkish-character addresses correctly.

    What is tested? şükrü@örnek.com and çiçek.com.tr are valid

    Form-checking browser extension

    Try a page's email fields with test addresses and report the result.

    What is tested? Enter the test address in a sign-up form and report if it is rejected
